Paramètres de BreachWatcher

Gestion du Cache Local

Pour préserver la fluidité de navigation et éviter les requêtes réseau répétitives, les résultats d'analyse sont mis en cache localement dans votre navigateur.

Par défaut : 7 jours

À propos de l'extension

BreachWatcher est une extension 100% autonome. Elle interroge directement la base de données publique Have I Been Pwned, les flux d'actualités récents et une base de référence intégrée sans passer par un serveur intermédiaire.
